# 福州大学校园指南 FZU Wiki

这里是一个由福州大学的学生们共同维护的知识库，旨在为福州大学的学生提供一个方便的学习和生活参考。

## 内容维护说明

content目录及其子目录下的\_meta.js存放的是当前目录中的文件/目录和网站侧栏显示的标题的对应关系。每一个mdx文件为一篇文档。

图片资源存放于public目录。

## 启动项目

```bash
yarn install
yarn dev
```

## 图片转为 WebP

项目中图片需转换为 WebP ，使用 [AnyWebp](https://mail.anywebp.com/ch/convert-to-webp.html) 进行转换

**注：webp图像质量统一为80，gif和svg不宜转为webp**
