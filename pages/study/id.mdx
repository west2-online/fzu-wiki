# 学号与学院代号

## 学号编码规则

学号一般满足以下规则：共9位；左起第五位数值，1博士生，2硕士生，0,9普通本专科学生，8专升本学生，5夜大生，6函授生，7脱产生；研究生、成人教育生学号前1、2位，普通本专科及专升本学号左起3、4位，与其入学时间的年份一致。
